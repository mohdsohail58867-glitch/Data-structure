## Objective
The objective of this task is to implement fundamental data structures from scratch using C++. This project demonstrates how data structures store, organize, and manage data efficiently.

## Data Structures Implemented
1. **Singly Linked List**
   - Insert elements
   - Delete elements
   - Search for elements
   - Display the list

2. **Stack**
   - Push elements
   - Pop elements
   - View the top element
   - Display stack elements

## Technologies Used
- Programming Language: C++
- Compiler: GCC/G++
- Standard: C++17
- Version Control: Git and GitHub

## Time Complexity
| Operation | Linked List | Stack |
|---|---|---|
| Insert at Front / Push | O(1) | O(1) |
| Search | O(n) | Not applicable |
| Delete by Value / Pop | O(n) | O(1) |
| Display | O(n) | O(n) |

## How to Compile and Run
Make sure GCC/G++ is installed on your system.

Compile the program:

```bash
g++ -std=c++17 -Wall -Wextra task1_data_structures.cpp -o task1
```

Run on Linux/macOS:

```bash
./task1
```

On Windows, run:

```bash
task1.exe
```

## Testing
The program should be tested for:
- Insertion and deletion of elements
- Searching for existing and missing values
- Stack push and pop operations
- Stack overflow and underflow conditions
